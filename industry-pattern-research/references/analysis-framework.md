# 五维切分框架详解与券商案例

## 框架来源

本框架从一篇真实研究提炼：《北京券商30年搬迁史：Kimi 跑完 20 家券商得出的选址规律》（公众号「船长猫爸·商办资产航海团」，2026-08）。

## 五维切分框架

分析任何"行业企业行为规律"时，从五个维度切入：

### 1. 时间线（阶段演变）
- 把研究对象的历史分成若干阶段
- 每个阶段标注：聚集地、比例、标志性变化
- 找阶段切换的驱动因素（政策、周期、突发事件）

### 2. 流向（升级/降级）
- 每次迁移判断是升级（往更核心/更高档区域）还是降级（往外围/低成本区域）
- 两极化描述：谁在升级、谁在降级
- 对应到空间：升级流向哪、降级流向哪

### 3. 频次（定居/游牧）
- 统计搬迁间隔：是否两极分化（要么很久不动、要么频繁搬）
- 分类：长期定居型 / 长期游牧型 / 过渡短租型
- 对持有资产方的启示：入驻企业是"落地生根"还是"很快会走"

### 4. 性质（扩/缩租）
- 每次搬迁面积变化：扩租、缩租、持平
- 租金与面积的关系（如"面积扩大、租金下降"）
- 判断是真降级还是"扩张型消费降级"（成本与扩张并存）

### 5. 底层逻辑（为什么）
- 锚定什么？（对手方/客户/监管/人才池）
- 能级匹配？（头部=地标背书，中小=成本优先）
- 最终归宿？（自建楼宇/自有物业）
- 默认状态？（能不搬就不搬 / 频繁流动）

## 券商案例（示范输出）

- 时间线：1995-2005 CBD+燕莎 → 2005-2020 金融街鼎盛（50%+） → 2021-2026 多中心疏散
- 流向：升级→CBD；降级→丽泽及西城外围
- 频次：头部定居、中小游牧；大机构短租=过渡（总部未建成）
- 性质：只扩租不缩租；外迁典型"面积扩大+租金下降"+"功能分拆"（注册地/前台留守核心区，总部/中后台外迁）
- 逻辑：锚定对手方（证监会/央行/总行/保险资管）；头部必须地标背书；20家中11家已有总部大楼（归宿=买楼）；20家中10家从未搬迁（默认不搬）
- 预测：2027-2030 北京券商搬迁高峰（疫情后密集期延续）

## 可复用方法要点

1. 用 AI 批量跑长周期数据（如让 Kimi 梳理 20 家 30 年搬迁史）
2. 样本要全（覆盖行业代表企业）
3. 结论 = 现象 + 数据支撑，避免空泛
4. 做成系列（券商→律所→银行…），汇成跨行业对比表
5. 每个行业结论落到资产端/业务端可预测价值
